# LNX — Sitio web

Sitio estático (HTML + Tailwind vía CDN + Geist).

## Cómo correrlo local
Abre `index.html` directo en el navegador, o usa un servidor simple:

```
python3 -m http.server 8000
```

## Deploy
Este proyecto está pensado para desplegarse en Vercel como sitio estático (sin build step).
